# Standard Contract Test Samples

This folder contains standard-form Korean housing lease contract samples adapted
for OCR, field extraction, and risk-analysis testing.

Included samples:

- `sample_04_standard_form_caution.html`
- `sample_08_standard_form_mobile_tilted.html`
- `sample_12_standard_form_high_risk.html`

Each sample has a matching ground-truth JSON file.

Design goals:

- Follow the public standard lease contract structure closely enough for testing.
- Preserve the user-approved scenario content for each sample.
- Render cleanly as A4-like HTML for later screenshot/PDF generation.
